# Sketch Manifest

## Design Direction
MiPo (מי פה) — a personal leave-tracking tool replacing a manually-typed WhatsApp list.
Clean, utilitarian, data-dense feel (closer to a spreadsheet than a consumer app).
Hebrew, right-to-left. Mobile-first (Android phone is the primary device), but should
hold up in a desktop browser too. Target stack: Next.js + Supabase + Vercel (PWA,
installable via "Add to Home Screen"), single-user auth for v1.

## Reference Points
Google Sheets / Airtable (dense grid scanning), plain WhatsApp text list (what it replaces).
